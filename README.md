# StudySpace 💜
### Student Study Planner

StudySpace is a student study planner that helps students organize their tasks and improve productivity.

## Features
- Dashboard and study progress
- Add, edit and delete tasks
- Manage subjects
- Study calendar
- Focus timer
- Save data using Local Storage

## Technologies
- Java
- Spring Boot
- Maven
- HTML
- CSS
- JavaScript

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run: `.\mvnw.cmd spring-boot:run`
4. Visit http://localhost:8080
